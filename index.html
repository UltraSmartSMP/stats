Méthode

Comptage par cloc 2.06, complété par des définitions pour les langages maison :

    Avancement des tasks : lignes - [x] sur lignes - [ ] ou - [x] de specs/NNN-*/tasks.md (à défaut, de specs/NNN-*/tasks/*.md) dans le contenu commité de la branche docs, un relevé par commit qui change un fichier de tasks.

    Tokens : somme des compteurs usage (entrée, sortie, écriture et lecture de cache) des réponses des sessions et agents du projet, dédoublonnées par réponse, relevée tous les 50 commits ; aucun contenu n'est publié.

    Seuls les fichiers suivis par git sont comptés, tels qu'ils sont publiés sur la branche de chaque dépôt.

    Exclus

    Les fichiers binaires (.smpb, .smpo, .bin, images, archives, tout fichier non UTF-8 qui contient un octet nul), le code tiers embarqué (dossiers third_party, vendor), les dossiers .git, les liens symboliques et les sous-modules. Un fichier texte que cloc ne reconnaît pas est compté sous « Texte ».

    Le type « Données » regroupe les attendus de tests, les corpus générés, les preuves et les dumps du compilateur : le chiffre « hors données » les retire.

    Une ligne qui ne contient qu'un commentaire compte dans « commentaires » ; une ligne qui mêle code et commentaire compte comme code.

    Mise à jour

    Le générateur recompte après chaque synchronisation des dépôts, puis pousse ce site, que Vercel redéploie. La date affichée est celle du commit le plus récent compté.

    La page relit les chiffres toutes les minutes tant qu'elle est visible : un nouveau commit sur un dépôt s'annonce en bas de l'écran, avec un petit son que l'interrupteur du compteur de commits coupe.
